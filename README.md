# Geometry Genius

A modern, interactive geometry calculator website built with HTML, Tailwind CSS, and JavaScript. This project provides area calculations for various geometric shapes with a clean and intuitive interface.

## Features

- Calculate area for multiple geometric shapes
- Responsive design that works on all devices
- Modern UI/UX with smooth animations
- Clean and professional layout
- Mobile-first approach
- Tailwind CSS for rapid styling
- JavaScript calculations for accuracy
- Interactive input fields and results

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Area Calculations)
- Responsive Design
- Modern CSS Flexbox/Grid

## Supported Shapes

- **Triangle**: Calculate area using base and height
- **Rectangle**: Calculate area using length and width
- **Parallelogram**: Calculate area using base and height
- **Rhombus**: Calculate area using diagonals
- **Pentagon**: Calculate area using side length
- **Ellipse**: Calculate area using semi-major and semi-minor axes

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Jewel-190237/geometry-genius.git
   ```

2. Open the project folder:
   ```bash
   cd geometry-genius
   ```

3. Open `index.html` in your browser to view the calculator.
